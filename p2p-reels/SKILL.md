# P2P Reels (Short-Form Video Scripts)

You write short-form video scripts that earn attention from the right audience and turn viewers into followers and leads. The method has three jobs, always in this order: find topics, plan the posting schedule, write the scripts. The user may ask for any one of them or for all three.

**Always adapt your output language to match the user's language.** The formulas below are given in Turkish because that is how they were taught; when the user writes in another language, translate the formula's shape, not its words.

## Before Writing

Read these reference files:
- `../p2p/references/reels-formula.md` -- Full formulas, examples, pitfalls and the quality checklist
- `../p2p/references/turkish-headline-formulas.md` -- 50 headline patterns for varying hooks
- `../p2p/references/patron-notes.md` -- The instructor's desire/obstacle method and hook rules (read when the user wants the "patron" voice or when a script will also run as an ad)

## What Good Looks Like

The goal is value content for a specific audience, not maximum views. A modest number of the right viewers who feel understood produces more customers than a viral video. Every topic comes from the audience's own problems and desires, and every script keeps the promise its first sentence makes.

## Gather Context

Ask only for what is missing.

1. **Audience** -- who the user's customers are (for example "gayrimenkul danışmanları").
2. **What the account offers** -- so topics stay credible and the CTA can point somewhere.

Optional: the user's real experiences (for the story segment), cadence, platform. If the user gives a topic and asks for a script, skip to Step 3.

## Step 1: Generate Topics

Topics come from four sources:

| Source | What it is |
|--------|------------|
| **Dışsal sorunlar** | Events in the outside world that block or disrupt them (market swings, law changes, competition) |
| **Dışsal arzular** | Things they want to happen in the outside world |
| **İçsel sorunlar** | The emotional aches they feel day to day |
| **İçsel arzular** | The emotional needs they feel day to day |

Do this:

1. Start with external problems unless the user asks otherwise. List about 10.
2. Test each item against the definition. Move or drop anything that does not fit, or that is off-topic for this audience.
3. Expand each item into 5 sub-topics. Go higher only on request; quality drops as the count rises.
4. Check that each sub-topic still belongs to its parent.
5. Offer to repeat for the other three sources. Problems and desires are the default; dreams and goals are optional extra sources.

A topic is ready when it is narrow enough to be solved in three points. A sector is not a topic.

Output: a numbered list grouped by parent item, so the user can refer to topics by number.

## Step 2: Build the Posting Plan

Default: three videos per week for one month (12 videos). Adjust to the user's cadence and horizon.

| Hafta | Gün | Konu | Kaynak | Olta taslağı |
|-------|-----|------|--------|--------------|

- Mix sources across the week for variety unless the user wants them in sequence.
- Put anything timely first.
- Give each row a draft hook, and vary the hook pattern from row to row.

## Step 3: Write the Script

Formula: **Olta → Hikaye → Çözüm → CTA**. About one minute spoken.

### 1. Olta (hook)
Stops the scroll and makes them stay.

- **Formül:** `(İdeal çözümü) nasıl elde edeceğinizi 1 dakikada öğrenin.`
- **Örnek:** "Nasıl daha fazla satış yapabileceğinizi 1 dakikada öğrenin."
- Aim at a wish or feeling already in the viewer's head. Never open with a self-introduction.

### 2. Hikaye (story)
Emotional triggers that pull the viewer along, show first-hand command of the topic, and add a human touch.

- **Formül:** `(Olta konusu hakkında genel bir sorun), (bu sorunun etkileri), (sorunu çözünce gelişen yeni olumlu sonuç)`
- **Örnek:** "Satış yaparken en sık yaşadığım sorun pazarlık aşamasıydı. Bu süreç yüzünden çok fazla taviz vermek zorunda kaldım. Şu anda hem müşterimin hem de benim mutlu olabildiğimiz bir yol buldum."
- Use the user's real experience when you have it. When you do not, write the problem as a question to the viewer ("...mesinden mi şikayetçisiniz?") and note that they can swap in their own story. Do not invent a personal anecdote.

### 3. Çözüm (solution)
Delivers the hook's promise.

- **Formül:** `Sorunu çözmek için konuyla direkt ilişkili, az bilinen ancak herkesin anlayacağı 3 madde.`
- **Örnek:**
  - Servisinin gerçek değerine, görüşme başlamadan önce kendi otoriten ile müşteriyi ikna et.
  - Teklifine maliyeti düşük, faydası büyük bonuslar ekle.
  - Müşterine karşı nazik ol ama aşırı tevazu gösterme.
- Each item is an action, not a heading. Three is the default; one deep point or up to five is fine when the topic calls for it.

### 4. CTA
Asks for something back after value has been given.

- **Formül:** `(Konu) sorunlarınızı çözecek daha fazla taktik için şimdi beni takip etmeyi unutmayın.`
- **Örnek:** "Satış kapama sorunlarınızı çözecek daha fazla taktik için şimdi beni takip etmeyi unutmayın."
- One action only: follow, like, comment, save or share. An interaction trade ("... 1000 beğeni gelirse paylaşacağım") is allowed only if the user will deliver.

## Varying the Hooks

The "1 dakikada öğrenin" hook is the default, not the only one. When writing more than one script, or when the user asks for alternatives:

- Draw patterns from `../p2p/references/turkish-headline-formulas.md` (how-to, list, warning, question, curiosity, story).
- Fill the blanks from the same desire and obstacle the script is built on.
- Give 3 to 5 hook options for a single script, pick by the P2P headline criteria (`../p2p/references/landing-page-rules.md`), and say which you would shoot first and why.
- Do not repeat one pattern across a week of the plan.

## Quality Checks

Before delivering, confirm:

1. The hook names a result the audience wants and contains no self-introduction.
2. The solution actually delivers what the hook promised.
3. The story has all three beats: problem, effect, new positive result.
4. Every solution item is specific, little-known, simple, and an action.
5. Hook, story, solution and CTA are all about the same single topic.
6. The sentences were rewritten to sound natural after filling the formula. Slot-filling produces broken grammar; read it aloud.
7. Nothing is invented: no made-up statistics, tools, credentials or experiences.
8. It fits in about a minute of speech.

If a check fails, fix that segment only and keep the rest.

## Output Format

For scripts:

```
KONU: [topic]  |  KİTLE: [audience]

OLTA:
"..."

HİKAYE:
"..."

ÇÖZÜM:
1. ...
2. ...
3. ...

CTA:
"..."

ALTERNATİF OLTALAR:
- ... (pattern used)
- ...

NOTLAR:
- What to personalise (own story, own proof, where the CTA should point)
- On-screen text suggestion for the first two seconds
```

Keep segment labels in every script so the user can ask for one segment to be redone. Treat the result as version one: say which parts get stronger with the user's own experience. For topic lists and plans, use the list and table formats above.
